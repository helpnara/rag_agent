# 정보보안 지침 (샘플)

> 본 문서는 공개 데모용으로 작성된 **가상의 회사(샘플 주식회사) 문서**입니다.
> 실제 보안 지침이 아니며 어떤 실존 조직과도 관련이 없습니다.

## 1. 적용 범위
본 지침은 샘플 주식회사의 전 임직원 및 협력업체 상주 인력에게 적용된다.

## 2. 계정 및 비밀번호
1. 비밀번호는 **최소 12자** 이상으로 하고 영문 대소문자·숫자·특수문자 중 3종류 이상을 조합한다.
2. 비밀번호는 **90일마다** 변경하며, 최근 3회 사용한 비밀번호는 재사용할 수 없다.
3. 계정 공유는 어떠한 경우에도 금지한다.
4. 5회 연속 로그인 실패 시 계정을 **30분간 잠금** 처리한다.

## 3. 문서 등급 분류
| 등급 | 정의 | 반출 |
|------|------|------|
| 공개 | 외부 공개 가능한 자료 | 제한 없음 |
| 내부 | 사내 임직원만 열람 | 팀장 승인 |
| 대외비 | 지정된 담당자만 열람 | 본부장 승인 |
| 기밀 | 경영진 및 지정자만 열람 | 대표이사 승인 |

## 4. 외부 반출 및 클라우드 사용
1. **대외비 이상** 문서는 개인 이메일·외부 클라우드 저장소로 전송할 수 없다.
2. 생성형 AI 서비스에 사내 문서를 입력하는 행위는 **내부 등급 이상 문서에 한해 금지**한다.
3. 업무상 외부 전송이 필요한 경우 정보보안팀에 사전 승인을 받는다.
4. USB 등 이동식 저장매체는 등록된 암호화 장비만 사용한다.

## 5. 재택근무 보안
1. 사내 시스템 접속은 반드시 **회사 VPN**을 경유한다.
2. 공용 와이파이에서는 대외비 이상 문서를 열람하지 않는다.
3. 업무용 PC에 가족 등 제3자의 계정을 생성하지 않는다.

## 6. 사고 신고
보안 사고 발견 시 **즉시** 정보보안팀(내선 1234)에 신고하며, 자체 조치를 우선하지 않는다.
신고 지연으로 피해가 확대된 경우 별도의 책임을 물을 수 있다.

## 부칙
이 지침은 2026년 3월 1일부터 시행한다.
