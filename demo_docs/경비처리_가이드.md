# 경비처리 가이드 (샘플)

> 본 문서는 공개 데모용으로 작성된 **가상의 회사(샘플 주식회사) 문서**입니다.
> 실제 회계 규정이 아니며 어떤 실존 조직과도 관련이 없습니다.

## 1. 경비 청구 기본 원칙
1. 모든 경비는 **증빙(영수증·세금계산서)** 을 첨부해야 한다.
2. 사용일로부터 **30일 이내**에 청구한다. 기한 경과 시 팀장 사유서가 필요하다.
3. 매월 말일 마감, 익월 **10일 급여일에 함께 지급**한다.

## 2. 항목별 한도
| 항목 | 한도 | 비고 |
|------|------|------|
| 식대(야근) | 1인 15,000원 | 20시 이후 근무 시 |
| 교통비(택시) | 실비 | 22시 이후 또는 대중교통 불가 시 |
| 출장 숙박비(국내) | 1박 100,000원 | 수도권 120,000원 |
| 출장 숙박비(해외) | 1박 200,000원 | 지역별 차등 적용 |
| 도서구입비 | 월 50,000원 | 업무 관련 도서 |
| 교육비 | 연 1,000,000원 | 사전 승인 필수 |

## 3. 법인카드 사용
1. 법인카드는 **업무 목적으로만** 사용한다.
2. 사용 후 **3영업일 이내** 전표를 등록하고 영수증을 첨부한다.
3. 주말·공휴일 사용 시 사유를 반드시 기재한다.
4. 개인 용도로 사용한 경우 즉시 반납하고 해당 금액을 회사에 입금한다.

## 4. 출장비 정산
1. 출장 신청서는 출발 **5영업일 전**까지 제출한다.
2. 국내 출장 일비는 **1일 30,000원**, 해외 출장 일비는 **1일 60,000원**이다.
3. 항공권은 이코노미석을 원칙으로 하며, 6시간 이상 비행 시 임원에 한해 비즈니스석을 허용한다.
4. 출장 종료 후 **7일 이내** 출장 보고서와 정산서를 제출한다.

## 5. 접대비
1. 건당 **300,000원**을 초과하는 접대비는 본부장 사전 승인이 필요하다.
2. 접대 상대방의 소속·성명·목적을 전표에 기재한다.
3. 공직자 접대는 청탁금지법 기준을 준수한다.

## 부칙
이 가이드는 2026년 1월 1일부터 시행한다.
