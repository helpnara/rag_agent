# 인사규정 — 연차휴가 (샘플)

> 본 문서는 공개 데모용으로 작성된 **가상의 회사(샘플 주식회사) 문서**입니다.
> 실제 사규가 아니며 어떤 실존 조직과도 관련이 없습니다.

## 제1조 (목적)
이 규정은 샘플 주식회사 임직원의 연차유급휴가 부여 및 사용에 관한 사항을 정함을 목적으로 한다.

## 제2조 (연차 일수)
1. 입사일 기준 1년간 80% 이상 출근한 직원에게 **15일**의 연차유급휴가를 부여한다.
2. 계속 근로기간이 1년 미만인 직원에게는 1개월 개근 시 **1일**의 유급휴가를 부여한다.
3. 3년 이상 계속 근로한 직원에게는 최초 1년을 초과하는 계속 근로연수 **매 2년마다 1일**을 가산한다.
   가산휴가를 포함한 총 휴가일수는 **25일을 한도**로 한다.

## 제3조 (연차 사용 절차)
1. 연차 사용 희망일 **3영업일 전까지** 그룹웨어를 통해 신청한다.
2. 팀장은 신청일로부터 1영업일 이내에 승인 여부를 결정한다.
3. 반차는 오전(09:00~14:00), 오후(14:00~18:00)로 구분하며 **0.5일**로 계산한다.

## 제4조 (연차 촉진 및 소멸)
1. 연차는 발생일로부터 **1년간** 사용할 수 있으며, 미사용 시 소멸한다.
2. 회사는 소멸 6개월 전 미사용 연차 일수를 서면으로 통보한다.
3. 회사의 귀책사유로 사용하지 못한 연차는 **미사용 수당**으로 정산한다.

## 제5조 (특별휴가)
| 구분 | 일수 | 비고 |
|------|------|------|
| 결혼(본인) | 5일 | |
| 출산(배우자) | 10일 | 유급 |
| 사망(부모·배우자) | 5일 | |
| 사망(조부모·형제자매) | 3일 | |
| 예비군·민방위 | 해당일 | 증빙 제출 |

## 부칙
이 규정은 2026년 1월 1일부터 시행한다.
